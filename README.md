# Virtual Dog Park

A small browser app for meeting dog breeds and caring for a virtual companion.

Open `index.html` in a modern browser. No installation or account is required.
For consistent browser storage, serve the directory over HTTP.

## Features

- Read brief introductions to Beagles, Golden Retrievers, and Poodles.
- Adopt a dog with a name of 1–20 characters.
- Feed or play to increase happiness by 10, up to 100.
- Advance a day to reduce happiness by 5, down to 0.
- Watch a puppy become a young dog on day 2 and an adult on day 4.
- Restore progress from browser storage after a refresh.
- Confirm before clearing a saved dog.

Progress stays in the current browser. The app sends no data to a server.
If browser storage is unavailable, the app shows a message and works for the current session.

## Files

`index.html` contains the page. `style.css` controls the layout.
`script.js` handles interactions and storage. `assets/` contains original SVG illustrations.

The interface, code, and illustrations were created with AI assistance.
